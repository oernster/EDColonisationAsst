Linux

Any distribution with Flatpak

Download for Linux

Flatpak bundle (.flatpak)

Needs the Freedesktop 25.08 runtime, which Flatpak fetches from Flathub the first time.

Install it with flatpak install --user edcolonisationasst.flatpak, then start it from your applications menu or with flatpak run uk.co.oernster.EDColonisationAsst. You can still build it yourself from a checkout instead; running it straight from source also works.
