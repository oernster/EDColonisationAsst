How it works

There is nothing to configure and nothing to sign in to. EDCA finds your journal, starts a small web server on your own machine and opens your browser.

Four steps

STEP 1

Install

Download and run the installer from the Releases page; there is nothing to configure.

STEP 2

Launch

EDCA starts a local web server and opens your browser for you. There is nothing to sign in to.

STEP 3

Play

It reads your journal straight away and keeps the colonisation and carrier views current as you fly.

STEP 4

Go cockpit

Open EDCA on a tablet using your PC's network IP on the same Wi-Fi and mount it beside the cockpit.

The first launch

The first run pauses to read every journal already on your machine, so that you start with the colonisation history you have actually flown rather than from empty. It says so while it does it, naming the file it is on and how much is left, so it is a wait you can watch rather than guess at. Later launches skip straight past it.

What you need

Elite Dangerous on PC

with Horizons and Odyssey (the Trailblazer colonisation update)

Any modern browser

Chrome, Edge, Firefox or Safari

Windows 10 or 11

EDCA ships as a Windows installer from the Releases page

Optional second screen

a tablet beside the cockpit for immersion
